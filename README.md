# 林地变化估计与有限补测的报告认证

业务资料均为合成记录。表头字段及跨表引用见 `fixtures/format.json`。

## 数据说明

cells 记录各小班面积、抽样层和历年边界，未纳入写作 `-`。争议小班的边界以确认附在 zone_v2，revision_known 是复核得知时间。共有比较按同时入区的面积；全期现况可包括新入区。plots 的 design_weight 是抽样设计权重，response 为 ok 或 inaccessible；paired 仍须核对两年是否确有可配记录。validation-plots 与正式估计样方不同，提供分类器类别检查。
情景中的认证宽度按比例点区间宽度计。field-options 的总工时包含共同路线到场时间，effort 的 reserved_cells 是确定复测地块，取消其安排需另审。路线不含的地块不能当作完成复测。

CSV 使用 UTF-8、逗号分隔，无引号与内嵌换行。未提供的字段是空字符串，作为关系值的 `-` 表示不适用。多值字段用竖线分隔，数值和日期单位见业务约定。

## 资料检查

使用 Node.js 22.23.4，依赖仅为 Node.js 标准库。运行 `npm ci --ignore-scripts --offline` 准备工作区。

运行 `npm run check:materials` 检查合成交接资料的字段与记录引用。运行 `npm test` 检查交接资料的读取和校验。

## 报告流程

运行 `npm run report` 输出年度报告（JSON 到标准输出）；`node tools/run-report.mjs --dir 目录` 可指向更新后的资料目录。测绘员提交边界确认或复测回执后更新 CSV 重跑即可，省级简报、分区复核与补测经费用同一份输出。`签发依据` 栏目可回看该版用过的影像产品、样方与面积归属，`认证核查` 列出需暂停的证书，`不受影响的可用结果` 列出其它分区可继续使用的结论。

口径约定：

- 共有比较只含两年均在区的小班；全期现况可含新入区；跨区小班在同一版报告中只按 published_zone 归属一次，面积不重复记给两个区。
- 变化只认有效配对样方（paired 且两年记录均 ok 且类别非空）；现况用报告年度全部有效记录。区间按设计权重与未响应状态计：未响应部分按比例点并吞入区间。
- 某层完全没有实测时保留 [0,1] 全宽、标记未确认并列出区间依赖的可解释假设，不用整区平均或其他层结果写成已确认。
- 影像显示的"变化"与地面配对证据对账，用独立样方给出的产品类别偏差分清真变化与新旧产品口径差异；影像缺边与地面未知在 `可追溯缺口` 中点名。
- 认证宽度按比例点区间宽度计；公开结论只发布有覆盖的共同区域结果，复议中与未实测地块列入排除项。
- 补测建议按通行窗口、路线总工时（含共同路线到场时间）、既定复测样方与最紧缺的报告证据比较；路线不含的地块不算完成复测，取消既定复测安排需另审。

模块划分：`src/tables.mjs` 读取与类型化，`src/scope.mjs` 边界与面积归属，`src/estimate.mjs` 地面证据估计，`src/validation.mjs` 产品偏差与对账，`src/certify.mjs` 证书与公开结论核查，`src/plan.mjs` 补测规划，`src/report.mjs` 组装报告。
